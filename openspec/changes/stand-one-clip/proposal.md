# Proposal

## Why

Стенд HIL управляет Ватериусом через плату METF по Wi-Fi, а прошивают плату другой прищепкой —
программатором `waterius_flasher`. Разработчику нужна одна прищепка на оба дела: прошил и сразу
гоняешь тесты. Программатор 0.7.0 уже умеет всё, что стенд брал у METF (`#wave`, `#wave stat`,
`#hold`/`#release`, лог по `#log`), а сервер времени переехал на роутер стенда
(`2.5.0-waterius.1`, команда `ntp`). Кроме того, роутер 2.5.0 пускает в консоль только по SSH, и
нынешний `router.py` с ним уже не работает: стенд сейчас не поднимается вовсе.

## What Changes

- **BREAKING** Стенд управляет Ватериусом через программатор по USB-serial: кнопка, импульсы входов,
  удержание входа (датчик протечки), лог ESP8266. Плата METF, её клиент и проверки её Wi-Fi уходят
  из стенда целиком.
- Программатор стенд находит сам по USB (Espressif, VID 303a) и ответу на `#info`; перед прогоном
  проверяет версию (не ниже 0.7.0) и что плата на прищепке (`#board`).
- После каждого теста стенд отпускает линии, не закрывая приём лога: пачки дожидаются конца,
  удержания снимаются `#release`.
- **BREAKING** Консоль роутера — SSH (порт 2323, вход по паролю из `stand.ini`), одно соединение на
  прогон, ключ хоста закрепляется в `stand.ini` при первом входе и сверяется дальше.
- **BREAKING** Сервер времени — на роутере (`ntp start|time|stop|drop|stat`), устройство ходит к нему
  по адресу точки стенда. Прогон без роутера (`--norouter`) блок N пропускает.
- Тест D7 подаёт серию и нажатие одной пачкой — без второго потока.
- `stand.ini`: секция `[metf]` уходит, появляется `[programmer]` (`port`, пусто — искать);
  в `[router]` — `host_key`.
- Документы стенда (`README.md`, `rules.md` — где упомянута METF, `01_wt32-eth01.md`, `CLAUDE.md`
  репозитория) и самотесты (`selftest/`) — под новую оснастку.

## Capabilities

### New Capabilities

- `stand-control`: как стенд HIL управляет оснасткой — программатор на гребёнке (воздействия, лог),
  консоль и сервер времени роутера, подъём прогона и уборка после теста.

### Modified Capabilities

Нет: в `openspec/specs/` спек стенда ещё нет.

## Impact

- Код: `Utils/hil/` — новый `programmer.py` вместо `metf.py`; `dut.py`, `logwatch.py`,
  `stand.py`, `clock.py`, `router.py`, `config.py`, `conftest.py`, `rescue.py`, `discover.py`,
  `portal.py`, `test_meter.py` (D7), `test_ntp.py`, самотесты.
- Зависимости: `metf_python_client` и `requests` (если больше не нужен) уходят из
  `requirements.txt`, приходит `paramiko`.
- Железо: одна прищепка — программатор с прошивкой 0.7.0; роутер с `2.5.0-waterius.1`. Обе уже
  на месте.
- Прошивка Ватериуса и страница `/factory/waterius2` не меняются.
