## 6a. Найденное по дороге

- [x] 6a.1 `router.py::dhcp_reserve` слал имя устройства через `-- <имя>` (форма из вики),
      прошивка отвечала `excess option`, и резервирование не создавалось. Имя убрано
- [x] 6a.2 Ошибка при этом проглатывалась: `excess option` и `missing option` не входили в
      `ERROR_MARKERS`, `cmd()` не бросал исключения. Оба маркера добавлены
- [x] 6a.3 Добавлен `dhcp_reservations()` — читает `show mappings` в словарь MAC -> адрес
- [x] 6a.4 `Net.verify_dut()` проверяет перед первым правилом фильтра, что по `dut_ip` сидит
      `dut_mac`, и падает с внятным текстом. Пустой `dut_mac` больше не проходит молча
- [x] 6a.5 Фильтр стенда не работал вовсе: `acl_add` слал лишнее слово `add`, прошивка молча
      ничего не делала, а `acl_rules()` не понимал формат `show acl` и всегда возвращал пустой
      список. На этом стоят `internet_down`, `cloud_down`, `mqtt_down`
- [x] 6a.7 Результат команды подтверждается состоянием: `cmd_checked()` читает его обратно
- [x] 6a.6 Тесты наследовали настройки соседа: `BASELINE` и `Stand.ensure_baseline()` приводят
      устройство к известному состоянию перед каждым тестом, сверяясь с последней посылкой —
      лишнего сеанса не будет, если всё и так совпало
