## 2. Прошивка платы

- [ ] 2.1 Собрать схему прошивки: USB-TTL `TX`→плата `RX0`, `RX`→`TX0`, общая земля; питание
      3,3 В от отдельного источника, **не** от переходника
- [ ] 2.2 Перевести в режим загрузки: замкнуть `IO0` на `GND` и подать питание
- [ ] 2.3 Найти порт: `ls /dev/cu.usbserial-*`
- [ ] 2.4 Стереть флеш: `esptool.py --chip esp32 -p <порт> erase_flash`
- [ ] 2.5 Прошить четырьмя файлами по проверенным адресам:
      `esptool.py --chip esp32 -p <порт> --before default_reset --after hard_reset write_flash -z --flash_mode dio --flash_freq 40m --flash_size detect 0x1000 firmware_wt32_eth01/bootloader.bin 0x8000 firmware_wt32_eth01/partition-table.bin 0xf000 firmware_wt32_eth01/ota_data_initial.bin 0x20000 firmware_wt32_eth01/esp32_nat_router.bin`
      (адрес приложения `0x20000`, а не `0x10000`, как говорит вики проекта)
- [ ] 2.6 Снять перемычку `IO0`–`GND`, перезапустить питание
- [ ] 2.7 Проверить: открыть консоль на 115200, выполнить `version` — печатается версия
      прошивки; в логе загрузки нет циклической перезагрузки

## 4. Удалённая консоль по проводу

- [ ] 4.1 По USB задать пароль: `set_router_password <пароль>`
- [ ] 4.2 Разрешить оба интерфейса: `remote_console bind ap,sta` — `sta` здесь означает

- [ ] 4.3 Включить и закрепить порт: `remote_console enable`, `remote_console port 2323`
- [ ] 4.4 `restart`, затем проверить с рабочей машины: `nc <ip> 2323`, ввести пароль,
      выполнить `version`
- [ ] 4.5 Проверить, что управление не рубит само себя: по сетевой консоли `ap disable`,
